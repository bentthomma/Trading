# ExtremeLab Architektur

Maßgeblich für diesen privaten S02-Arbeitsstand:

- `../../evidence/S02/architecture.md`: Verantwortungen, tatsächliche Quellen und Vertrauensgrenzen.
- `../../evidence/S02/domain-contract.json`: versionierter Fachvertrag, gebundenes Schema.
- `../../evidence/S02/capability-matrix.json`: Fähigkeiten sind keine Autorisierung.
- `../../evidence/S02/adr-001.md`: Architekturentscheid und nicht aktivierte Grenzen.
- `../../evidence/S02/source-bindings.json`: tatsächliche Originaldateien, Member und Hashes.
- `../../evidence/S02/scope-resolution-draft.json`: vorbereitete, noch nicht aktivierte Pfadauflösung.

Eine Darstellung oder Datei in diesem Ordner ist kein installierter Endpunkt und keine Handelsfreigabe.
