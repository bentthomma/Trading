cTrader Web öffnen · Offizielle Anleitung

Die Anwendung verwendet ausschliesslich das Datenprofil und fest erlaubte Leseabfragen. Ein kopierter /trading/mcp-Link wird nicht verwendet, sondern durch den festen /data/mcp-Endpunkt ersetzt. Der Token selbst kann weitergehende Rechte besitzen: wie ein Passwort behandeln.

Der Token wird für maximal 8 Stunden verschlüsselt in einem HttpOnly-Cookie gespeichert, an deine Website-Sitzung gebunden und nur serverseitig an cTrader gesendet. Keine Speicherung im Quellcode, in LocalStorage oder im Archiv. Nach Ablauf der cTrader-Sitzung ist eine neue Verbindung nötig.

Entfernen löscht die Verbindung in diesem Browser, widerruft aber nicht den Token bei cTrader. Eine anbieterseitige Sperre muss in cTrader erfolgen.
